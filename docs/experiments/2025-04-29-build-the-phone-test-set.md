# Build the phone test set

Date: 2025-04-29
Who: Lea Fontaine
Uncertainty: U1 Small model on faded thermal paper

## Plan (written before the run)

Hypothesis: 1,200 receipts from 6 phone models give a stable accuracy number (within 1%).
What changes: First test set: receipts from staff and pilot merchants, labelled twice.
Setup: 6 phone models, 3 lighting set-ups, 40% thermal paper older than 6 months.

## Result (written the same day)

Result: Two labellers agreed on only 91% of fields: faded receipts were read differently by each; accuracy varied 2.4% across random halves.
Learned: A third labeller for faded receipts and a written labelling guide before comparing models.
Outcome: Partly worked
